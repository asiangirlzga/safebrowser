# Lite Browser (Android)
Build the APK (pick one). Put build.yml at .github/workflows/build.yml in your repo:
1. GitHub: create a new repo, upload this folder, open Actions > "Build APK" > Run workflow, download the `LiteBrowser-apk` artifact.
2. Android Studio: File > Open this folder, Build > Build APK(s) (use the release variant for the small size).
Install the .apk on your phone (allow "install unknown apps").
